# OGP画像について

## 必要な画像

### ogp.jpg
- **サイズ**: 1200x630px
- **用途**: SNSシェア時のOGP画像（デフォルト）
- **推奨内容**: 小林畳商店のロゴ + キャッチフレーズ + 背景（畳の画像など）

## 作成方法

1. **デザインツールで作成**
   - Canva、Figma、Photoshopなどを使用
   - テンプレート: OGP画像 1200x630px

2. **推奨デザイン**
   - 背景: 畳の写真（和の雰囲気）
   - テキスト: 「小林畳商店 | 大阪市福島区の畳職人」
   - フォント: 和風で読みやすいフォント
   - カラー: Primary色（#8b9474）を使用

3. **配置**
   - 完成した画像を `ogp.jpg` として保存
   - このディレクトリ（`app/public/images/`）に配置

## その他の画像

このディレクトリには以下の画像も配置することを推奨します：

- `logo.jpg` - 会社ロゴ（LocalBusiness構造化データで使用）
- `hero-*.jpg` - ヒーロー画像（各ページのメインビジュアル）
- `work-*.jpg` - 施工例の画像
